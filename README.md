

 🧾 Gestión de Clientes con Tkinter y SQLite

Este proyecto es una aplicación de escritorio básica desarrollada en Python que permite gestionar clientes mediante una interfaz gráfica construida con Tkinter y una base de datos SQLite.

 📋 Características

- Agregar nuevos clientes.
- Listar todos los clientes existentes.
- Actualizar información de un cliente.
- Eliminar clientes seleccionados.
- Persistencia de datos mediante SQLite.

 🛠️ Requisitos

- Python 3.x
- No requiere instalación de paquetes externos (usa solo librerías estándar: `sqlite3` y `tkinter`)

 📦 Instalación y uso

1. Clona este repositorio o copia el archivo `.py` a tu equipo.

2. Ejecuta el script en tu terminal o IDE favorito:

   ```bash
   python gestion_clientes.py
   ```

3. Usa la interfaz gráfica para:
   - Ingresar datos en los campos de texto.
   - Agregar un cliente con el botón correspondiente.
   - Seleccionar un cliente de la lista para actualizar o eliminar.

 🗃️ Estructura de la base de datos

La base de datos `agencia_servicios.db` se crea automáticamente al iniciar la aplicación si no existe.

Tabla `Clientes`:

| Campo       | Tipo    | Descripción              |
|-------------|---------|--------------------------|
| ID_Cliente  | INTEGER | Clave primaria           |
| Nombre      | TEXT    | Nombre del cliente       |
| Direccion   | TEXT    | Dirección del cliente    |
| Telefono    | TEXT    | Teléfono de contacto     |
| Email       | TEXT    | Correo electrónico       |
| Plan_ID     | INTEGER | ID del plan asignado     |
